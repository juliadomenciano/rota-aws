Amazon RDS

Banco relacional gerenciado: MySQL, PostgreSQL, MariaDB, Oracle, SQL Server e Db2. A AWS cuida de instalação, patches, backups e failover; você cuida de schema, queries e acesso. Não dá SSH no servidor (exceto RDS Custom, para Oracle e SQL Server com acesso ao SO).

Existe também o Multi-AZ DB cluster (um primário e dois standbys legíveis, failover mais rápido) para MySQL e PostgreSQL.

  • Backups automáticos com retenção de até 35 dias e point-in-time restore; snapshots manuais ficam até você apagar. Restaurar sempre cria uma instância nova.
  • Criptografia com KMS só na criação. Para criptografar um banco existente: snapshot → cópia criptografada → restaurar.
  • Storage auto scaling, IAM database authentication (MySQL/PostgreSQL), senha no Secrets Manager com rotação.
  • RDS Proxy: pool de conexões, failover mais rápido, ótimo com Lambda.
Pegadinha nº 1 de banco: "alta disponibilidade, failover automático" = Multi-AZ. "Relatórios deixam o banco lento" = read replica. O standby Multi-AZ de instância não serve leitura.

Amazon Aurora

  • Relacional da AWS compatível com MySQL e PostgreSQL, com mais performance que o RDS comum.
  • Storage distribuído: 6 cópias em 3 AZs, cresce sozinho. Até 15 réplicas de leitura com failover automático para uma delas.
  • Endpoints: writer (cluster), reader (balanceia entre réplicas) e custom (grupo de réplicas, ex.: só as maiores para analytics).
  • Aurora Serverless v2: capacidade escala em frações conforme a carga. Para carga variável, imprevisível ou ambientes de dev.
  • Aurora Global Database: uma Região primária e até várias secundárias de leitura, replicação tipicamente abaixo de 1 segundo; promover a secundária em caso de desastre (RPO de segundos, RTO de cerca de 1 minuto).
  • Cloning (cópia rápida para teste), Backtrack (voltar no tempo sem restore, só Aurora MySQL).

Números de réplicas, Regiões secundárias e tempos de failover mudam; confirme na documentação do Aurora.

Amazon DynamoDB

NoSQL chave-valor e documento, serverless, com latência de milissegundos de um dígito em qualquer escala. Sem joins: modele pelos padrões de acesso.
