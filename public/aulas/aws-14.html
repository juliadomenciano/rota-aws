Amazon CloudWatch

RecursoPara que serve
MetricsSéries numéricas. EC2 manda CPU, rede e disco a cada 5 min (ou 1 min com detailed monitoring). Memória e espaço em disco não vêm por padrão: precisam do CloudWatch Agent.
Custom metricsMétricas da aplicação (pedidos/min), inclusive de alta resolução (1 s).
AlarmsDisparam ação quando a métrica cruza um limite: SNS, Auto Scaling, ações de EC2 (stop, reboot, recover), Systems Manager.
Composite alarmsCombina alarmes (A E B) para reduzir ruído.
DashboardsPainéis, inclusive de várias contas e Regiões.
Synthetics / RUMCanários que testam a API ou o site de fora; monitoramento de usuários reais no navegador.
Pegadinha: "monitorar uso de memória da instância" = instalar o CloudWatch Agent. O hypervisor não enxerga a memória dentro do SO.

CloudWatch Logs

  • Organizados em log groups e log streams, com retenção configurável (o padrão é nunca expirar: configure para economizar).
  • Metric filters transformam padrões nos logs ("ERROR") em métricas para alarmes.
  • Logs Insights: consultas interativas nos logs.
  • Subscription filters: enviar logs em tempo real para Lambda, Kinesis ou Firehose (e daí para S3/OpenSearch).
  • Exportar para o S3 para retenção barata e análise com Athena.
  • Criptografia com KMS no log group.

AWS X-Ray

Tracing distribuído: acompanha uma requisição pelo API Gateway, Lambda, ECS, DynamoDB e chamadas HTTP, mostra o service map e onde está a lentidão ou o erro. Hoje também via OpenTelemetry (ADOT) e CloudWatch Application Signals.

AWS CloudTrail

  • Registra chamadas de API: quem, o quê, quando, de onde. Vem ativo com 90 dias de Event history (management events).
  • Para guardar mais tempo: crie uma trail para o S3 (e opcionalmente CloudWatch Logs). Organization trail cobre todas as contas.
  • Management events (criar instância, mudar policy) x data events (GetObject no S3, invocação de Lambda): data events são desligados por padrão e cobrados.
  • Log file integrity validation prova que os logs não foram alterados. Proteja o bucket com Object Lock e MFA Delete.
  • CloudTrail Insights: detecta atividade de API fora do normal. CloudTrail Lake: consultas SQL nos eventos.

AWS Config

  • Registra a configuração dos recursos e o histórico de mudanças ("como estava este Security Group na terça?").
  • Config rules (gerenciadas ou próprias) avaliam conformidade: bucket criptografado, volume EBS criptografado, porta 22 aberta.
  • Remediação automática com documentos do Systems Manager Automation.
  • Conformance packs e aggregators para várias contas e Regiões.
  • Não impede a ação: detecta e corrige depois. Para impedir, use SCP ou policy.
