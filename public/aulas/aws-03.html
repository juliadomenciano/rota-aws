O que é EC2

Amazon EC2 é alugar uma máquina virtual (instância) por segundo ou por hora. É IaaS: você escolhe e cuida do SO. Ao criar, você responde 5 perguntas:

PerguntaNome AWSObservação
Qual SO e software base?AMIImagem regional; copie para outra Região para usar lá. Crie AMIs próprias ("golden AMI") para subir mais rápido.
Quanta CPU e RAM?Instance typeEx.: m7g.large = família m, geração 7, processador Graviton (g), tamanho large.
Como entro?Key pair / Session Manager / EC2 Instance ConnectSession Manager dispensa porta 22 aberta e chaves.
Quem chega pela rede?Security GroupFirewall stateful da instância.
Onde ficam os dados?EBS ou instance storeEBS persiste; instance store some ao parar.
User dataScript que roda no primeiro boot (como um postinstall). Bootstrapping: instalar pacotes, baixar código.
Instance metadata (IMDS)169.254.169.254: a instância descobre o próprio IP, a AZ e as credenciais da role. Prefira IMDSv2 (com token), mais seguro.
Instance profileO "envelope" que leva a IAM Role para dentro da instância. Credenciais temporárias e rotacionadas.

Famílias de instância

CategoriaFamíliasQuando usar
Uso geralT, MWeb, apps comuns. T é burstable (acumula créditos de CPU); bom para carga baixa com picos curtos.
Otimizada para computaçãoCBatch, encoding de vídeo, HPC, servidores de jogo.
Otimizada para memóriaR, X, zBancos em memória, cache grande, análise em tempo real.
Otimizada para armazenamentoI, D, HMuito IOPS local: NoSQL, data warehouse, OLTP pesado.
Computação aceleradaP, G, Inf, TrnGPU, treino e inferência de ML, renderização.
Pegadinha: instâncias Graviton (letra g, ARM) costumam ter o melhor preço por performance. Se a questão pede "melhor custo-benefício sem mudar muito", migrar para Graviton é forte candidata (se a aplicação roda em ARM).

Security Groups

  • Só regras de Allow. Não existe Deny em Security Group.
  • Stateful: se a entrada foi permitida, a resposta sai automaticamente.
  • Padrão: toda entrada bloqueada, toda saída liberada.
  • A origem pode ser um IP, um CIDR ou outro Security Group (o jeito certo de ligar camadas elásticas).
  • Fica no nível da ENI (placa de rede) e pode ser usado por várias instâncias.
Internet ──443──▶ [ALB  sg-alb ]
                     │ 80  (origem: sg-alb)
                     ▼
                 [EC2  sg-web ]
                     │ 5432 (origem: sg-web)
                     ▼
                 [RDS  sg-db  ]
Pegadinha: "bloquear um IP específico" não se faz com Security Group (não tem Deny). Use NACL (na sub-rede) ou AWS WAF (na camada HTTP).

Modelos de compra (o assunto mais cobrado de custo)

Pegadinha: "carga constante de 3 anos + quer trocar de família no futuro" = Compute Savings Plans. "Licença de software por core físico" = Dedicated Host. "Processamento que pode ser interrompido e retomado" = Spot. Mistura comum: base em Savings Plans + pico em On-Demand/Spot.

Percentuais de desconto variam por tipo e Região; confirme na página de preços do EC2.
