SageMaker e Bedrock

Amazon SageMaker AIPlataforma para construir, treinar e implantar modelos próprios: notebooks, treinamento gerenciado, endpoints de inferência, pipelines de MLOps.
Amazon BedrockAcesso por API a modelos de fundação (IA generativa) de vários fornecedores, com bases de conhecimento (RAG), agentes e guardrails, sem gerenciar infraestrutura.

Regra de prova: problema comum e bem definido = serviço de IA pronto. Modelo próprio com dados próprios = SageMaker. Texto/imagem gerados por IA = Bedrock.

Padrões de economia que viram resposta

  • Computação: rightsizing → Graviton → Savings Plans/RIs para a base → Spot para o que é interrompível → desligar fora do horário (scheduled scaling, Instance Scheduler) → serverless para carga intermitente.
  • Armazenamento: classe certa e lifecycle no S3, Intelligent-Tiering, gp3 em vez de gp2, apagar snapshots e volumes órfãos, EFS IA.
  • Banco: Aurora Serverless v2 ou DynamoDB on-demand para carga variável; provisioned + reservas para estável; cache para reduzir leitura.
  • Transferência de dados: entrada na AWS é grátis; saída para a internet é cobrada; tráfego entre AZs e entre Regiões custa. Use CloudFront (saída mais barata e menos chamadas à origem), gateway endpoints para S3/DynamoDB em vez de NAT, mantenha tráfego na mesma AZ quando possível.
  • Licenças: trocar engines comerciais por Aurora/PostgreSQL; Dedicated Hosts só quando a licença exige.
