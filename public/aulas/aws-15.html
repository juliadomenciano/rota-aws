AWS KMS

Em trânsito = TLS/HTTPS. Em repouso = dados criptografados no disco. O KMS cria e guarda chaves que nunca saem dos HSMs do serviço, integra-se a dezenas de serviços (S3, EBS, RDS, DynamoDB, Lambda) e registra cada uso no CloudTrail.

Tipo de chaveQuem gerenciaDetalhes
AWS ownedAWS, invisível para vocêPadrão de alguns serviços; sem controle nem auditoria
AWS managed (aws/s3, aws/ebs)AWS, na sua contaRotação automática anual; não dá para editar a key policy nem compartilhar com outra conta
Customer managedVocêKey policy própria, rotação configurável, pode desativar/agendar exclusão, compartilhar entre contas, importar material de chave
  • Key policy é obrigatória e é a principal forma de controlar quem usa a chave (junto com IAM e grants).
  • Envelope encryption: o KMS gera uma data key; o serviço criptografa os dados com ela e guarda a data key criptografada. Por isso o limite de 4 KB do Encrypt direto não atrapalha arquivos grandes.
  • Multi-Region keys: mesma chave em várias Regiões (DR, Global Tables, dados que cruzam Regiões).
  • Chave apagada não volta: a exclusão tem espera de 7 a 30 dias. Snapshots criptografados copiados para outra Região/conta precisam de uma chave lá.
Pegadinha: compartilhar um snapshot ou AMI criptografado com outra conta exige chave customer managed com a key policy liberando a outra conta. Com chave AWS managed não dá.

  • ACM: certificados TLS públicos grátis com renovação automática para ELB, CloudFront e API Gateway (não para instalar direto em EC2). Certificados importados não renovam sozinhos.
  • AWS Private CA: autoridade certificadora privada para certificados internos.

WAF, Shield e Firewall Manager

AWS WAFFirewall de camada 7 no CloudFront, ALB, API Gateway, AppSync e Cognito. Regras gerenciadas (SQL injection, XSS, bots, IPs ruins), rate-based rules (limite por IP), geo match, IP sets.
Shield StandardGrátis e automático para todos: proteção contra DDoS de camadas 3 e 4 (SYN flood, UDP reflection).
Shield AdvancedPago: proteção avançada para EC2, ELB, CloudFront, Global Accelerator e Route 53; acesso ao time de resposta (SRT); proteção de custos contra a escala causada pelo ataque; WAF incluso para os recursos protegidos.
Firewall ManagerAplica regras de WAF, Shield Advanced, Security Groups e Network Firewall em todas as contas da organização.
Pegadinha: WAF não se associa a um NLB nem diretamente a uma EC2. Para proteger uma EC2 com WAF, coloque um ALB ou CloudFront na frente.
